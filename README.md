# smartJobBot

AI 自动化投递简历 - 多平台 AI 海投助手

## 简介

多平台 AI 海投助手是一款浏览器油猴脚本（Tampermonkey Userscript），支持 BOSS直聘、智联招聘、前程无忧、拉勾网、猎聘等主流招聘平台，提供一键批量沟通、AI 智能回复、自动发送简历、可视化数据看板等功能。

## 快速开始

📖 详细操作使用说明请查看 → [使用指南.md](./使用指南.md)

## 功能特性

- 🚀 一键海投：自动筛选职位 + 批量沟通
- 🤖 AI 智能回复：接入 DeepSeek 等大模型，自动回复 HR 消息
- 📄 简历分析：上传简历文件，AI 自动分析生成摘要
- 📊 数据看板：投递趋势、岗位/公司排行、地区分布可视化
- 🔧 多平台支持：BOSS直聘（完整）、智联/前程无忧/拉勾/猎聘（基础）
- ⚙️ 灵活配置：经验/学历/薪资/求职类型多维筛选
